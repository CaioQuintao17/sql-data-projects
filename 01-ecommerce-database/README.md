# 01 — E-commerce Database

Banco de dados relacional para uma pequena operação de e-commerce.

## 📌 Contexto
Simula o banco de dados de uma loja virtual, com clientes, 
produtos, pedidos e itens de pedido.

## 🗂️ Estrutura do banco
- clientes
- produtos
- pedidos
- itens_pedido

## 🧠 Conceitos aplicados
- CREATE DATABASE / CREATE TABLE
- PRIMARY KEY / FOREIGN KEY
- INNER JOIN
- Funções agregadas (COUNT, SUM, AVG)

## 📁 Arquivos
- `schema.sql` — criação das tabelas
- `data/inserts.sql` — dados de exemplo
- `queries/consultas.sql` — consultas de análise
