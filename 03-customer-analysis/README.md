# 03 — Customer Analysis (Banco Cooperativo)

Análise de comportamento de clientes (cooperados) de uma instituição 
financeira, com base em contas e transações.

## Estrutura do banco
- clientes
- contas (ligada a clientes)
- transacoes (ligada a contas)

## Conceitos aplicados
- CREATE TABLE / ALTER TABLE / FOREIGN KEY
- INSERT / DELETE
- GROUP BY / HAVING
- INNER JOIN / LEFT JOIN
- Funções agregadas (SUM, COUNT, AVG)

## Arquivos
- `schema.sql` — estrutura do banco
- `data/inserts.sql` — dados de exemplo
- `queries/consultas.sql` — consultas de análise
